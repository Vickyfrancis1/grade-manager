# Student Grade Manager

A command-line program to record students' scores, calculate averages and letter grades, and rank the class.

## Features

- Add students with several scores
- Average and letter grade for each student
- Ranking from highest to lowest average
- Duplicate names and empty score lists are rejected
- Data saved to a JSON file
- Unit tests for the grading, duplicate check and ranking logic

## How to run

```
python grade_manager.py
```

## How to run the tests

```
python test_grade_manager.py
```
